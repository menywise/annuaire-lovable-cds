découpé pour l'éditeur SQL de Lovable. Exécuter les fichiers **un par un, dans l'ordre (1 à 10)**,
chacun en entier. Tous sont rejouables. Si un bloc échoue, noter son numéro et le message.

12 empreintes Lovable, module `false`, réglages).

Règle de l'éditeur de Lovable : il coupe le script à chaque ligne vide ; aucun bloc n'en contient
dans une fonction.
